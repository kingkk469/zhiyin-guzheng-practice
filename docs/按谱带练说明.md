# V0.11.0 按谱带练

乐曲练习转为“听示范、跟着弹”。取消自动检测演奏节奏是否准确，不再判提前/拖后、扣节奏分、显示综合成绩或生成旧评分建议。带练不申请麦克风、不采音、不要求先校音。

## 使用

1. 从首页选择曲谱，或在“曲谱管理”导入 JSON 后点击“预览”。
2. 核对简谱、八度、附点、时值、休止和展开后的反复顺序。
3. 设置基础速度（20–240 拍/分钟）和连续小节范围，点击“开始带练”。
4. 播放中可拖动速度滑块；数字输入完成后点击其他位置或按回车生效。变速保留当前乐谱位置和谱内快慢比例，音高不变。
5. 暂停冻结声音和谱面，继续从暂停位置播放；重新播放从所选范围开头开始。后台或音频挂起自动暂停，返回后点击继续。

目前只支持现有结构化 JSON 格式，模板可从网页下载；没有图片自动识谱。谱面当前支持 D 调、音高 MIDI 38–86，拍号分母 4、分子 2/3/4/6；反复由 `order` 显式展开；休止用 `midi: null`；每个音用 `beat` 和 `duration` 记载时值；渐变速度用 `tempo`。旧文件中的 `pitch`、`rhythm` 支持标志仍兼容，但不影响带练，也不要求新文件填写。导入和录音均留在本机。

## 声音与授权

`lib/guzheng-voice.ts` 是本项目原创的程序合成音源，不含第三方采样、不下载远端音色，也不使用用户真实录音。采用拨弦瞬态、带轻微非谐性的弦振动模态、不同泛音衰减和短暂琴体共鸣构成古筝拨弦近似音色；不是旧版三角波蜂鸣，也不是钢琴或日本筝采样。

模态/弦/琴体建模方向参考公开研究 [An Efficient Modal-based Approach Towards Guzheng Sound Synthesis](https://arxiv.org/abs/1910.05447)；代码与参数自行实现，没有复制论文配套音频或实现，不宣称复现论文模型或取得实琴测量精度。此音色仍是近似合成，音色听感需要用户和老师试听。单个拨弦自然衰减约4秒；未实现摇指、撮、按滑音等完整技法，有技法标记的片段按所记单音演奏，不冒充老师示范。

音符的起止由曲谱时间轴调度；暂停/变速立即停止旧声源，恢复在当前音的相应衰减位置播放。调速只改变调度时间及光标时钟，不改变音源的 `playbackRate`（固定1），因此不靠加速录音改变音高。

## 记录与兼容

- 新带练记录使用 `zhiyin-v3-accompaniment`，只记录曲谱版本、范围、基础速度和完成状态，不评分。播放中变速后记录结束时的基础速度，不描述为整次固定速度。
- 原 `zhiyin-v2-records` 与 IndexedDB 原音/样本/人工纠正保持不变；既有调音与录音复核功能保留。
- 旧成绩原数据仍在浏览器中，但界面只展示历史元信息与音高检测计数。导出只包含元信息、音高与原始音高证据，不包含节奏分、时差评级、综合分或旧建议，不静默改写旧记录。
- 旧评分规则仅保存在 `tests/legacy/` 供历史数据测试，网页运行代码不导入它们。`npm run test:legacy` 用于历史算法回归，不代表当前带练功能。

## 验证与限制

- 当前功能49项单元测试：音源在44.1/48kHz下音高、振幅及衰减，导入时值、休止、反复、渐变速度、分段，暂停/续播/调速及取消未完成启动，已有音高/校音/录音规则。
- 桌面 Edge 的真实 Web Audio 输出图、390×844手机尺寸交互已验证：有音频能量，休止/附点/反复/变速调度，暂停冻结与续播，播放中调速不改变音源速率，范围选择、记录刷新、旧数据保留与导出过滤，无麦克风调用和上传请求。
- 原音复核浏览器回归验证：原字节下载、刷新恢复、纠正答案、完整备份恢复、批量重测、取消、直接录音下载与存储失败退路。精调回归保留真实偏差与余音隔离。
- 这些是程序合成输入与桌面浏览器验证，不代替 iPhone Safari、Android 实机、微信内置浏览器及古筝音色的真人听感验收。手机需点按钮开启声音，并检查系统媒体音量；校音/录音仍需 HTTPS 和麦克风授权。

本机测试结果和截图位于 `outputs/`，不提交私人录音或报告。
