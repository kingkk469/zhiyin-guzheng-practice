# V0.9.0 录后复核与声学事件门控

## 修改

- 共用 pluck-evidence：按20ms块估计录音的低能量背景，判音检查相对噪声底与新增频谱的谐波结构。已有低噪声基线不会随长段音乐升高，避免把持续演奏学成噪声。
- 相邻起音先独立分析；两个均有明确声学证据且不足110ms时才拒判。弱触发不会否决随后明确的拨弦。近距两事件的流式分析可能延至约220ms，保持原起音时间。
- RingingTracker保留实际已听弦音：新候选若为其较高泛音、新增比例不足且整体能量未明显上升，保留“未判断”，不强行报成新音。更近的同音来源优先，避免将同弦重拨因更早的低音来源误作泛音。此规则可能牺牲部分弱八度拨弦的覆盖率，仍须独立真琴验证。
- 录后主列表显示残差拨弦结果，未判断/排除事件可展开；Basic Pitch旧候选折叠为诊断区，JSON继续完整保存，原音下载和完整备份不变。
- 关联乐谱为用户明确选择，默认不关联。支持主应用已有内置/导入乐谱，记录id、版本、标题、展开音序快照。整段序列对齐允许多音、缺音、错音；仅从声学分数相差8%以内且通过新增证据的模糊候选中辅助选择，明确音高不改写。录后参考乐谱是全曲音序，不是实时节奏评分；片段应关联相应片段乐谱。
- 每次运行保存referenceScore；重测旧样本沿用最后运行的参考快照。样本truth不传给worker，仅用于结果核对。
- 序列比较明确标注“多出项、缺少项、替换项”；用户答案未提供起音时间时，不宣称能区分物理错音与一多一漏。未判断单独统计，不将排除的非拨弦事件混进音序。
- 声学规则 residual-offline-2，练习规则0.9.0-score-context-trial，worker缓存版本同步升级。

## 验证与边界

91项自动测试通过，包含弱噪声后96ms真拨弦、弱重复音、连续音噪声基线、泛音变化与独立八度、录后乐谱对齐和硬拒绝不能被谱子复活。11首合成曲183音，三种余音条件分别182/182/178正确；0误判错音、0错弦被接受，仍有1漏检及最长余音条件4未判断，与V0.8.0基线一致。这不是总体真琴准确率。

浏览器录后复核测试覆盖主列表、导出、原音字节下载、刷新恢复、备份恢复、批量重测、取消和存储失败退路。私人原音与逐音真值仅用于本地验证，不包含在Git提交或公开站点中。当前未完成独立留出真琴数据集和iPhone多机型验收。
