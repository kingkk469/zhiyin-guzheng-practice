# V0.10.0 乐谱驱动判定与异常情况

## 从历次问题得到的规律

1. 古筝余音叠加会使单帧单音检测产生低音、八度错误和重复候选。一次拨弦应当先寻找新增声学成分，再判断音高；录音中出现一个频率不等于又拨了一次弦。
2. 只知道目标音序，不能解决节奏问题。必须保存音符时值、休止、速度图和反复顺序，再生成真实时间轴。
3. 固定按整拍计算宽松容差，会把短音中的明显抢拍放过。匹配音符的搜索窗口和节奏满分窗口必须分开。
4. 音高正确不等于节奏正确。只显示绿色勾、只给总分，会掩盖提前、拖后和附点节奏被弹平的问题。
5. 谱子是参照，不能当成录音证据。实际弹错、多弹、少弹必须保留；听不清不能按谱补齐。
6. 合成音验证不能替代真琴。保留原始录音、完整候选、规则版本和人工纠正，才能持续复现问题。

## 当前处理流程

导入结构化曲谱 JSON → 校验时值连续、拍数、休止和技法支持 → 展开反复与练习范围 → 积分变速图生成目标起音时间 → 编译每个音的节奏规则 → 新拨弦检测及余音门控 → 有界音序匹配 → 独立音高/节奏评分 → 逐音依据与本地录音复核。

上传图片并不自动保证识谱正确；现有图片转录谱和导入 JSON 都需要先预览核对。V0.10.0 使用这些已录入的时值，不新增图片 OCR。

### 新增：按谱编译节奏容差

每个可评节奏的音取自身实际时长，以及前一个相邻可评音到当前音的起音间隔，较短者作为局部时值。休止和不支持片段不会作为前一个可评音跨过去连接。

满分容差 = min(原模式的整拍容差, 局部时值 × 60%)。保留原来的满分、半分、零分三级；超过满分但未超过两倍容差得半分。短音不会再被固定的最小毫秒容差覆盖。

60% 是试验规则，不是已证实的人类节奏感知阈值。它兼顾当前采音波动与短音辨别，后续需要更多独立真琴录音验证。音符匹配窗口保持原样，避免把能识别的晚音误算成错音。

### 新增：检查局部长短关系

连续三个相邻且音高可靠匹配的起音，比较谱中与实际的两段起音间隔。谱中比例至少 1.8:1（或反向），实际中间音落在总间隔的 40%～60%，总速度差不超过 20%，且相对位移超过 max(60ms, 短间隔 × 40%)，则提示长短/短长节奏接近均分，中间音最高半分。

此处的归一化仅用于判断局部关系，不会平移目标时钟，也不会抵消绝对抢拍、拖后。休止、错音、漏音、未判断、自由节奏及复杂技法不组成该证据。下一音到达后才可确认这种模式；绝对偏差仍立即判定。

## 演奏情况与处理边界

| 情况 | 当前策略 | 状态 |
|---|---|---|
| 正常按谱弹、变速、分段、谱中反复 | 使用展开后的目标时间轴及局部时值 | 已有，新增节奏计划覆盖 |
| 提前、拖后，短音挤占下一音 | 有界匹配保留音高位置，按局部容差扣节奏分 | 本版更新 |
| 长短或短长弹成近似均分 | 三个可靠起音确认，指出中间音节奏问题 | 本版新增 |
| 整段快慢漂移 | 保留绝对偏差与小节速度趋势，不自动追着演奏改拍点 | 已有；趋势不重复扣分 |
| 固定采音时差 | 只使用明确填写的设备校准；不把平均演奏偏差当时差 | 已有 |
| 同音连续拨、实际八度跳进 | 需要新的拨弦证据，不能仅因同音/整数倍频就删掉 | 已有 |
| 旧弦余音、泛音、背景噪声 | 起音前后残差、噪声底、谐波结构和已听到的弦共同判断 | 已有；轻拨仍可能未判断 |
| 错弦、少弹、多弹、休止中拨弦 | 强声学证据优先；报告保留错音、漏音、多音 | 已有；近邻同音仍可能歧义 |
| 弹错后回头重弹 | 连续证据检测丢谱，不移动参考时钟；恢复前未判断 | 已有 |
| 弱拨、削波、麦克风中断、候选冲突 | 保留未判断或中断，不根据谱子编造音符 | 已有 |
| 摇指、撮、按滑音、短于约110ms连音 | 当前单次拨弦方案不保证支持，不强行给出正确答案 | 尚不支持完整评分 |
| 自由速度、自由节奏 | 尊重曲谱关闭节奏评分的声明 | 已有 |
| 长音提前停止/过长 | 本版评价起音和起音间隔，不用古筝自然衰减推断精确止音 | 尚未实现止音评分 |
| 上传谱子时值录错 | 导入结构校验只能发现结构错误，仍需人工预览核对 | 人工确认谱面 |

## 报告与验证

新增逐音节奏问题列表，显示音高状态、提前/拖后毫秒、局部模式；简谱节奏问题显示橙色。导出保留每个音的容差、局部间隔、模式及两段实测间隔。报告明确总音数与未判断数。旧报告保留原规则，不静默重算。

本次私有真琴样本在本地完整重跑采音和评分后，标出四处用户指出的抢拍，没有新增其他节奏错误，音高100、节奏94；这是用于本版修正的样本验证，不是独立准确率评估。音频、人工标注及逐音私有结果不提交 Git。

自动测试覆盖现有11首谱、导入谱变速和反复、早音晚音、长短/短长均分、恒定时差、休止/错音/未判断断开证据、快速细分，以及原有余音、弱触发、重复音和错音不纠正等回归。

后续采样应分别包含正常附点、故意均分、同音反复、八度跳、休止中误触、故意错音、渐快渐慢和轻拨，保留设备与速度。先固定规则，再用新增录音验收，避免只适配一份录音。
