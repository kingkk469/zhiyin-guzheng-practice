# 手机试弹反馈：调音与动态曲谱修复

日期：2026-09-23。版本：V0.3 / 评分记录0.3.0-trial。

## 结论及证据边界

用户反馈已调准的古筝在网页上没有一个音通过。当前没有用户手机型号、浏览器版本或失败时的原始单弦音频，因此不能宣称已经复现并解决其设备上的全部原因。

已确认旧实现存在两处可复现的失效路径：

1. `detectPitchYin`的固定RMS门槛为0.012，音头检测另有0.014门槛。弱音虽有稳定周期，仍会被当作无音高或无拨弦。合成衰减谐波信号幅度0.003时，旧函数全部返回无音高；这属于输入幅度检测失败，并不是证明琴没调准。
2. 巡检只在起音帧建立琴弦候选，起音帧受瞬态/旧弦影响无法定位时，即使之后音高稳定也不再尝试。新增测试复现这一链路，现保留300ms起音候选窗口以等待清晰帧。

此外旧代码简单平均降采样到约12kHz，减少了高音区每周期采样点。新版取消此操作，按实际AudioContext采样率检测。并未把浏览器统一假定成44.1kHz，也不把测出的音高吸附到目标音。

调音器先估计连续频率，再换算最近音名与音分；不能先假定用户一定弹了目标音，再用校正结果证明音准。本次保留独立测量和错误八度，不自动迁就整体偏调。A4固定440Hz；目前仍只开放D调21弦。

## 本次改动

- 4096点原采样率窗口，约20ms一次，先去直流偏置，再用Pitchy MPM检测。最低RMS0.0005，检测清晰度门槛0.8，MPM峰选择参数0.93。数值均为试验参数，不是发布验收标准。
- 音头检测下限调整为0.0015，保留相对音量上升和最小起音间距；是否为可评分音仍需音高置信与持续验证。
- 起音有300ms定位恢复机会，校音仍要求±15音分内稳定约0.5秒。错误八度、噪声、低置信、过载不通过。
- 调音页显示实际音名/Hz，支持保存检测数值、采样率、浏览器与输入设置；不含录音、不自动上传。
- 新手俯视图标明演奏者位置、1至21弦、向外换弦与琴码右侧拨弦区。
- 依据用户示例视频改为固定排版完整简谱、4小节一行（窄屏2小节）、红色竖线光标、小节线、八度点、减时线、附点与增时线，以及下方每拍折线。反馈符号保留；只有进入不可见的新谱行时调整谱面容器，不逐音滚整个页面。
- 顺弦巡检全21音标注弦号及音名，移除逐音卡片背景，用连续红线提示进度。曲目中未提供的指法、歌词、连音线不凭空编造；示例视频未复制到公开网站，也未作为老师授权曲目导入。

## 验证

46项自动测试通过。其中新音高用21弦 × 2采样率（44.1/48kHz）× 2幅度 × 3偏音（-30/0/+30音分），共252个合成衰减谐波样本验证，误差均在3音分内。还验证弱音实际通过校音、直流偏置、错误八度不通过、静音及确定性宽带噪声被拒绝、轻拨起音与起音后恢复。

浏览器合成音完成21弦精调、巡检偏高/偏低/漏拨、复查、评分及录音管线回归；桌面和手机尺寸截图检查通过。这些都不是手机麦克风或真实古筝准确率。原有测试未覆盖用户报告的弱音与起音失效场景，不能继续用“合成纯音通过”推断真琴可用。

下一步实测：在用户同一手机上先用逐弦精调，记录第一、十一、二十一弦的实际Hz，与另一调音器在同一基准A4=440、同一D调下比较。再覆盖衰减、不同力度、余音叠加和连续拨弦。若仍不一致，可由用户主动保存检测信息供排查；真实录音仍需另行明确授权，不自动收集。
