# V0.8.0 乐谱顺序辅助判音

2026-09-25。用于测音准模式。调音器保持独立；无乐谱的录后复核不使用人工答案作为识别条件。

## 实现

- 频谱判音保留前四个实测候选、实测音高偏差、起音前后能量和新增比例，经 worker 送到评分层。
- 已明确听到的音优先，即使谱子中没有这个音也保留。仅在声学证据不确定时，允许未匹配、顺序向前且位于原时间窗中的谱音辅助消歧。
- 乐谱只能从距最高声学评分 8% 以内、新增比例至少 20%、未触及空弦搜索边界的候选中选择。保留候选实测音分，不吸附到标准音高。
- 不确定事件最多等到原起音后 220ms；期间若下一个明确音到达，可利用相邻谱音关系排除一部分歧义。时间戳、节奏容差不变。不是任意变速跟谱，也不是整曲离线最优对齐。
- 保存近三秒实际识别到的弦音来源；仅在候选与已听到的弦同音或为其第 2～8 次泛音、无明显新增能量且起音后能量未明显上升时，标记疑似余音并不生成新音符。不能只因为谱子里没有而排除。
- 独立起音的同弦重拨和八度跳不按音名去重。漏弹、多弹、错音与未判断继续分别处理。
- 报告增加 `recognition`，保留全部判断事件、原始首选、四个候选、处理结果及可能的余音来源；页面显示辅助确认、排除和未判断次数。原始录音功能保留。
- 规则版本 `0.8.0-score-context-trial`，避免与旧规则成绩混比。worker URL 更新，避免复用旧脚本。

## 边界

这仍是保守的规则模型：三秒来源记忆和每次前后能量比较，不是逐弦完整物理衰减估计。相位、共鸣波动或噪声产生很强的新能量时仍可能误判；来源弱、证据不足时保留未判断。更轻的真实重拨可能被误判为余音，需要实琴样本验证阈值。

候选接近时借助谱子也可能倾向预期音，因此不以合成测试宣称真琴准确率提高。需使用未参与调参的真琴样本分别检查错音误接受、漏检、多检、未判断和延迟；不以排除更多候选作为单独成功指标。

## 验证入口

`npm test` 包含乐谱辅助、连续同音、余音与八度保护、缺失/额外音、导出证据、等待确认时序，以及用户八音序列的真实流式代码合成输入测试。故意改弹第四个音必须仍判错。

`node scripts/benchmark-residual-stream.mjs` 使用 11 首内置谱、三个余音条件，并故意改弹部分音。它只代表合成回归。

`npm run test:audio` 检查真实浏览器 worker → 音频接口 → 乐谱判断 → 保存报告的证据传递，并回归录音回放入口。
