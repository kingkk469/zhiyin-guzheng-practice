# 知音 · 古筝智能陪练 V0.3.4

依据本任务确认的 PRD V0.1，在已有 V0.1 原型上实现的**本地试验版**。服务所有学员，流程为：21弦校音 → 选曲与自定义速度 → 实时音符/节奏反馈 → 报告和片段重练。

**尚未达到正式教学发布门槛。** 真实古筝识别准确率、教师内容审核、iPhone/iPad/Android 实机与20分钟连续运行验收尚未完成。内置10个原创练习单元明确标为待审核；合成参考音不是老师示范。

手机试用入口：https://kingkk469.github.io/zhiyin-guzheng-practice/ 。GitHub Pages由main分支自动构建发布，以Actions部署成功为准。苹果使用Safari、安卓使用Chrome，点击开启麦克风并允许授权，建议横屏。录音和练习记录仍保存在使用设备的浏览器本地。其他旧托管站点不随本次GitHub部署更新。

## 启动

使用 Node.js 24（本轮实测24.13.0）。在本目录运行：

```powershell
npm ci
npm run dev
```

打开 <http://127.0.0.1:3219/>。生产预览使用 `npm run build`，再执行 `npm start`。

电脑 localhost 可调用麦克风；手机使用上述HTTPS试用入口，不能使用电脑的127.0.0.1地址。

## 可以体验什么

- 默认顺弦巡检：21弦动态简谱、4拍预备、每根1/1.25/1.5秒三档，光标引导从第一弦拨到第二十一弦；实时显示通过、偏高、偏低、未听清与漏拨，结束后只复查问题弦。
- 保留逐弦精调：D6到D2，±15音分、连续0.5秒、置信度门槛；校音可选，未完成也可真实练习，刷新重新校音。巡检速度是待真琴验证的试验参数。
- 麦克风授权、安静基线检查、无声、过载提示。本地 AudioWorklet 采音、Pitchy / MPM 基频、音头检测；无云端音频请求。
- 10个原创试练单元：基础指序、长短音、同音、休止、八分音符、附点、音区、变速、反复和技法边界。
- 数值/滑块设置速度、连续小节选择、两小节预备拍。固定目标时间表，分开显示目标与实际位置。
- 线性BPM渐变的时间积分、反复顺序展开、独立音高与节奏支持标记。
- 错音、漏音、多弹、早/晚与未判断；单次漏音恢复；疑似回头重弹和连续两小节丢失时暂停。
- 60%音符＋40%节奏试算；覆盖率门禁；未完成、丢谱和中断不产生总分；逐小节速度趋势不重复扣分。
- 最多3条有小节依据的建议、85%减速重练、本次录音分小节回听、主动下载、JSON报告导出。
- 本机练习历史、删除、同曲谱版本/评分版本/范围/速度比较；模拟报告和真实报告分开。
- 内部JSON导入、校验、版本、反复、技法、审核信息与有授权说明的示范音频索引。

没有古筝时，进入任意曲目，勾选“无琴体验 · 模拟演奏”。这条入口不调用麦克风、不能为真实模式通过校音、不会产生真实录音；报告一直标注模拟。

## 验证命令

```powershell
npm test
npm run typecheck
npm run lint
npm run build
npm run test:render
# 另一个终端先 npm start；本机默认使用已安装的 Edge。
npm run test:browser
npm run test:audio
npm run test:sweep
```

`test:audio` 使用程序合成的虚拟音流，**不会开启真实麦克风**。它验证浏览器采音管线、21弦门槛、分析、报告和录音链路，不验证真实古筝效果。

`test:sweep` 使用合成音验证顺弦巡检：18根准确、1根偏高、1根偏低、1根漏拨，随后逐弦复查、通过门槛、重新巡检及手机布局。`npm test`现含52项规则与音频处理测试。真实余音叠加、轻重拨弦及最佳巡检速度仍需试弹。

`outputs/` 保存本地截图与测试结果，不提交Git。浏览器测试默认地址127.0.0.1:3219，使用Edge；其他系统把测试中的 `channel: 'msedge'` 改为已安装的Chrome通道，或安装Playwright Chromium后移除channel。

## V0.3 手机反馈修复

- 增加俯视拨弦图，标出身体一侧、第一/第二十一弦、换弦方向和琴码右侧拨弦区。
- 按用户提供视频的呈现方式改为完整简谱：分行小节、八度点、减时线、附点/增时线、红色移动光标、拍点折线。只在目标换行且不可见时滚动谱面容器，不牵动整个页面。视频本身未上传，未导入其曲目或示范音频。
- 用Pitchy 4.1.0的MPM替代线上旧YIN实现；按AudioContext真实采样率分析4096点窗口，取消约12kHz的简单平均降采样。实际依赖版本以package-lock.json为准。
- 修复弱音被固定门槛丢弃、起音首帧未识别后整弦丢失的问题；±15音分/0.5秒通过标准保留。显示实际音名/Hz，不把音高吸附到目标。
- 详情及公开参考项目：[调音与动态曲谱修复](docs/调音与动态曲谱修复.md)。

## V0.3.1 光标与换行

光标独立使用requestAnimationFrame读取练习/采音时钟，不再依赖50ms的界面刷新。相邻小节连续定位，换行前约350ms预先带出下一行，曲谱容器以约320ms缓动滚动，行尾/行首各75ms淡出入，避免红线斜穿谱面。变速使用与评分一致的速度时间表反解，暂停立即冻结。顺弦巡检也使用逐帧光标及平滑换行。

本机Edge手机尺寸测试记录首秒60个不同光标位置，换行最大逐帧滚动约6px，整页不移动、暂停冻结；这是当前测试环境结果，不承诺所有手机固定60fps。测试命令：`node tests/browser-motion.mjs`，可通过TEST_BASE_URL指定实际网址。

## V0.3.2 精调误导修复

用户反馈设备为iPhone微信内置浏览器。增加微信环境提示，请复制网址到Safari对照试弹，尚未证明微信是误差根因。精调通过后锁定弦号，改用“下一根弦”手动切换，避免上一根的余音被拿去与更低的下一根比较而指向偏高。切入精调或换弦时清空测量，只接收选择之后的新起音；起音前100ms不用于读数。重新拨同弦时重新验证，不沿用旧通过结果。

稳定读数取最近160ms窗口中位数，至少4帧及80ms观测，波动超过20音分时不显示方向；±15音分/0.5秒通过门槛没有放宽。测得音高与目标相差超过100音分时隐藏方向指针、提示核对弦号。数值稳定性优化不等于真实频率误差已校准。

52项规则/音频测试通过；针对浏览器回归验证了通过后弦号不变、换弦余音不产生偏高指针、真实+35音分仍显示偏高、微信提示可见。微信提示用UA模拟，仅验证界面，不是实际iPhone微信采音测试。

## V0.3.3 调音对照

精调同时显示目标与实测 Hz、稳定状态、带符号音分及量程；周期匹配指标不再暗示为准确率。通过范围仍为 ±15 音分，不代表测量精度。新增手动捕获稳定读数、输入另一调音器 Hz、计算差值和本机 JSON 导出；不录音、不上传、不据此自动修正。先统一 A4=440 Hz 与十二平均律，在同一设备位置分次拨同一弦，至少重复三次并覆盖高、中、低音弦。真实古筝与 iPhone Safari/微信对照仍待实测，未宣称精度提升。

## V0.3.4 精调刻度与稳定布局

保持原有浅色界面，新增 ±50 音分弧形表盘，每小格 1 音分、每5格中刻度、每10格数字。无稳定读数时隐藏指针，超过量程显示提示；固定音名、频率、判定、偏差与采音信息区域高度，避免有声/无声切换引起布局跳动。刻度分辨率不代表实测准确率。

## V0.3.5 手机精调
手机竖屏精调采用紧凑仪表布局，隐藏全站导航和流程步骤，保留巡检返回、拨弦帮助、21弦选择、麦克风及完成入口；帮助和对照按需展开，展开后允许滚动。

## V0.3.6 刻度可读性
音名移到扇形中央并放大，指针缩为刻度附近的短针避免遮字；手机刻度盘使用完整可用宽度，加深加长每音分刻线与数字，保留单屏布局。

## V0.3.7 校音改为可选
按最新产品要求，取消21弦通过门槛，校音页可随时进入选曲；开始练习直接准备麦克风并检查采音环境。最近5个已匹配音中至少3个同向偏差35–100音分时提示可能琴弦不准，不自动停止、不改变评分；去校音会结束并保存未完成记录。

## V0.3.8 声音节拍器
一个小节预备拍加全程声音节拍，三种音色和音量，首拍重音；使用音频时钟提前调度，跟随曲谱变速，暂停/结束/后台停止。外放模式保留跟拍与记录但不评音符、不评分；耳机隔离节拍声后可开启识别，真实设备漏音和时差仍需实测。

## V0.3.9 提供曲谱录入
新增《日常节奏小练习2》（胡冰青编配），按用户图片手工录入D调2/4、70拍、10小节；保留首小节休止、附点节奏、各音区，待老师核对。没有上传原图，也未声称自动识谱。节拍器默认音量从0.5提高到0.7，峰值包络提高3倍并适度延长；最大单声部峰值限制0.72。手机实际响度仍取决于系统媒体音量。

## V0.4.0 两种练习模式
新增独立跟练/测音准选择。跟练不申请麦克风，不录音，不显示检测标记，结束显示跟练记录；测音准模式提示戴耳机隔离节拍声，申请麦克风并实时检测、录音与报告。切换到跟练启动时关闭此前校音采音；暂停/后台继续停止节拍。

简谱减时线现按一拍分组连接：同一拍内连续短音符共用第一条线，更短时值按层连接，跨拍/休止/间隙断开。《日常节奏小练习2》每小节分为两组，附点八分与十六分相连，两个八分相连。

## V0.4.1 跟谱不中断与宽容度
识别丢失/疑似回头重弹仅提示，谱面与节拍继续；不确定区段标灰，连续3个匹配音后恢复，发生过丢谱的记录不输出总分。候选匹配在既有时间窗内兼顾音高，避免相邻密集音错位。测音准新增默认宽松（±50音分、拍长22%且至少110ms）和标准档；不改校音精度、不移动目标拍点，记录参数区分比较。实际手机误报改善仍待复测。

## V0.4.2 简谱留白
减时线整体下移8个SVG单位，为数字底部留白；低音点同步下移，实际演奏位置圆标右移避免与低音点重叠。按拍分组保持不变。

## V0.4.3 连续短音匹配与报告可信度

修复短音起音落到相邻音符时间附近时，仅按时间距离导致的串位：只在原有有界匹配窗口内优先匹配可靠音高，保留真实节奏偏差，不自动平移目标时钟。可靠覆盖或支持范围不足80%、采音中断或跟谱丢失时，不展示分项成绩、不生成演奏纠错建议；历史报告展示也应用该限制。

新增相邻短音延后230毫秒仍正确匹配、窗口外音高不能抢占、低覆盖不出建议回归测试。此修复不等同于解决实琴余音混合识别；当前仍需实琴录音和设备验证，不能把合成测试作为实琴准确率证明。
