# 知音 · 古筝智能陪练 MVP

面向古筝初学者的手机 H5 陪练原型。应用通过浏览器麦克风在本地识别拨弦音头、音高与节奏，并根据结构化简谱进行实时亮谱和乐句反馈。

公开体验地址：<https://kingkk469.github.io/zhiyin-guzheng-practice/>

## 已实现

- 基本功与三首原创入门练习曲
- 合并式设备检查：麦克风、背景噪声、真实琴声与耳机节拍一次完成
- 基于 YIN 与连续帧中位数的古筝基频识别，降低强泛音造成的八度误判
- 三根关键琴弦自动调音门禁：每根需连续两次稳定在 ±20 音分内才能通过
- 错弦提示、无声超时清空、无声音不评分、低置信不标红
- 实时音头检测、错音/早晚/漏音判定
- 50%、70%、85%、100% 四档练习速度
- 可试听和调音量的本地节拍器、按曲目 BPM 的四拍预备、同步可视拍点
- 专注式电子简谱、非遮挡乐句反馈与练习总结
- 演示识别模式明确标注模拟数据，调音仍需两次模拟拨弦确认
- 浏览器本地练习记录、趋势页和老师工作台
- 老师可调整音高与节奏评分容差
- 默认不保存或上传原始录音

## 本地启动

```bash
npm install
npm run dev
```

请使用支持 Web Audio API 的现代浏览器，并通过 HTTPS 或 localhost 打开麦克风。真实判音建议在安静室内进行，手机位于琴码右侧约一臂距离，节拍器使用耳机。设备检查未通过时只能进入明确标注的“不计分练习”，不会生成误导性成绩。

## 当前边界

首版针对 D 调 21 弦古筝、固定结构化曲谱与明确单音音头。摇指、刮奏、和弦和复杂按滑揉颤暂不评分；低置信度结果显示为“未能确认”，不会直接标红。
