# 知音 · 古筝智能陪练 MVP

面向古筝初学者的手机 H5 陪练原型。应用通过浏览器麦克风在本地识别拨弦音头、音高与节奏，并根据结构化简谱进行实时亮谱和乐句反馈。

公开体验地址：<https://kingkk469.github.io/zhiyin-guzheng-practice/>

## 已实现

- 基本功与三首原创入门练习曲
- 环境噪声检查、三根关键琴弦调音检查
- 实时音高检测、音头检测、错音/早晚/漏音判定
- 50%、70%、85%、100% 四档练习速度
- 本地节拍器、电子简谱、乐句反馈与练习总结
- 演示识别模式，无古筝时也可完整体验
- 浏览器本地练习记录、趋势页和老师工作台
- 老师可调整音高与节奏评分容差
- 默认不保存或上传原始录音

## 本地启动

```bash
npm install
npm run dev
```

请使用支持 Web Audio API 的现代浏览器，并通过 HTTPS 或 localhost 打开麦克风。真实判音建议在安静室内进行，手机位于琴码右侧约一臂距离，节拍器使用耳机。

## 当前边界

首版针对 D 调 21 弦古筝、固定结构化曲谱与明确单音音头。摇指、刮奏、和弦和复杂按滑揉颤暂不评分；低置信度结果显示为“未能确认”，不会直接标红。
